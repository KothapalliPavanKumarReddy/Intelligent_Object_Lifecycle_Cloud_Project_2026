2. Proposed AWS Cloud Architecture

Target Production Architecture for Serverless, Event-Driven Satellite Ingestion

PROPOSED CLOUD DEPLOYMENT
Amazon S3 Archive Bucket
Raw multi-spectral satellite imagery object store
↓
Amazon EventBridge / S3 Event Notifications
Publishes ObjectCreated:Put events upon upload
↓
Amazon SQS (Simple Queue Service)
Buffers and throttles bursts of satellite ingestions
↓
AWS Step Functions Orchestration
State machine coordinating preprocessing, scoring, and tiering
↓
AWS Lambda Preprocessing Worker
Serverless container converting GeoTIFFs & contrast stretching
↓
Amazon Bedrock / Vision Foundation Model
Managed Multimodal Vision Model (e.g. Bedrock / SageMaker CLIP)
↓
Importance + Confidence Engine
Calculates semantic ranking score and classification confidence
↓
Amazon DynamoDB Metadata Catalog
Stores image object metadata, semantic score, tier tag
↓
S3 Lifecycle Policies & Object Tagging
Automated transitions triggered by DynamoDB stream / S3 Tagging

Monitoring, Observability & Security Subsystems

Amazon CloudWatch Real-time metrics, Lambda execution logs, and lifecycle anomaly alarms
Amazon SNS Automated alerts for low-confidence classifications or Glacier transitions
AWS IAM Least-privilege role policies for Lambda, Bedrock, and S3 bucket encryption
